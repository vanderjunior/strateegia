# PSCPP Study Cycle Profile

`marinha_dpc_pscpp_praticagem_study_cycle` is the canonical StudyFlow AI study-cycle guidance profile for PSCPP Praticagem.

## Scope

- Flexible guidance profile, not a fixed schedule
- Editable and user-overridable
- No automatic scheduler mutation
- No calendar mutation
- No runtime study-cycle mutation

## Historical Evidence

- `PSCPP/2011` and `PSCPP/2012 Prova Rosa` are used only as `strategy_and_style_reference`
- They are not current edital truth, current content scope, or mandatory bibliography
- Current edital alignment remains required

## Priority Blocks

1. Manoeuvrability, shiphandling, tugs, and restricted waters
2. COLREG, lights, marks, and sound signals
3. Restricted navigation, radar, ECDIS, tides, and passage planning
4. Arte Naval foundations
5. Legislation, meteorology, communications, and general knowledge

## Phases

- Base technical vocabulary
- Scenario consolidation
- Deepening and new question production
- Post-edital alignment

## Weekly Distribution

- Default 24h hint with proportional scaling when the user has more or fewer hours
- The proportions are guidance-only and user-overridable

## Rotating Cycle

- Deterministic 12-session rotation
- Includes a short simulado plus error review at the end of the cycle

## Session Structure

- Active review
- Directed theory
- Questions or question creation
- Error notebook and flashcards

## Question Training

- Guidance-only progression from topical weekly questions to partial simulados, complete simulados, and final error-driven review
- Linked to the PSCPP question style profile `marinha_dpc_pscpp_praticagem`

## Notebook System

- Concepts the banca confuses
- Fatal numbers and rules
- Scenario notebook

## Safety

- No answer key or gabarito output
- No scheduler mutation
- No automatic study-session assignment
- No LLM, RAG, or vector behavior
